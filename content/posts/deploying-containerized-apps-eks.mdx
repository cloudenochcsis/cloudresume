# Deploying Containerized Applications on Minikube and AWS EKS

Bridging the gap between local development testing on Minikube and multi-AZ production clusters on Amazon Elastic Kubernetes Service (EKS).

## Architecture Takeaways
- Containerizing microservices with multi-stage Docker builds.
- Provisioning managed node groups with AWS ALB Ingress Controller.
- Implementing zero-trust NetworkPolicies and IAM Roles for Service Accounts (IRSA).
